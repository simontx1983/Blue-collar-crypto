## Clean-browser production observation

- Before a choice, signed-out signup loaded the PostHog consent banner and sent Sentry envelope requests. The captured signup load showed no PostHog network requests. No signup form was submitted.
- Decline hid the banner, produced no visible PostHog request in that capture, and the Privacy page reported that analytics was off.
- Allow on the Privacy page initialized PostHog. Chrome showed feature/config requests and a PostHog event-ingest request. The event body was not decoded. Provider and route observations came from the browser Network panel rather than an exported archive.
- After withdrawal, a fresh Privacy page load still showed Sentry envelope requests and no PostHog request in the capture. The Privacy page reported that analytics was off. The sampled browser captures did not establish Vercel measurement traffic, even though the Web Analytics script URL responded in a separate HTTP check.

The first-party source scan found no other replay or tag-manager initialization in the scanned frontend files. It cannot rule out extensions or scripts served by external configuration.
